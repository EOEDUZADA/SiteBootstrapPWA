## Visão Geral

Um **Protótipo de Alta Fidelidade (Frontend-Only)** de e-commerce de periféricos voltado ao público gamer competitivo, projetado para praticar a aplicação da arquitetura **PWA (Progressive Web App)**.


### Stack Utilizado

* **HTML5 & CSS3:** Estilização customizada.
* **Bootstrap:** Utilizado para acelerar o desenvolvimento do layout, garantindo um design responsivo.
* **JavaScript (ES6+):** Manipulação do DOM
* **PWA Engine (Manifest & Service Worker):** Arquivos essenciais para transformar a estrutura estática em um aplicativo instalável e resiliente offline.
